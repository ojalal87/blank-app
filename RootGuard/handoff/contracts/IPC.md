# IPC boundary
JSON Schema is a language-neutral ENVELOPE specification, not complete operation validation or transport authentication. Kotlin DTOs must define every operation payload with unknown-field rejection, limits and typed backend validation. Do not ship a generic Map<String,Any> privileged handler.
Transport: use a maintained Android root-service library with verified Binder caller identity and package signer, scoped binder access and explicit session lifecycle; choose after compatibility review. If a separate native daemon is adopted, secure socket ownership, peer credentials and authenticated session handshake are required. No TCP listener.
Protocol version mismatch fails closed with UNSUPPORTED_PROTOCOL. Limit total decoded request to 256KiB initially; large plans use bounded authenticated chunks and digest, never writable temporary script paths. Validate expiry in elapsed realtime with matching boot ID. Initial session handshake returns actual boot ID; PROBE uses that session ID before accepting other operations. Keep idempotent request receipt cache and policy transaction journal across crashes.
Error codes: ROOT_DENIED, UNSUPPORTED_BACKEND, CAPABILITY_STALE, REVISION_CONFLICT, INVALID_PLAN, TOO_LARGE, EXPIRED_REQUEST, AUTH_FAILED, VERIFY_FAILED, ROLLBACK_FAILED, ATTRIBUTION_UNCERTAIN.
Sensor batches include protocol/version, boot ID, sensor ID, sequence range, dropped count and quality; never trust app-supplied UID mapping without helper-side revalidation. Each operation has a timeout and cancellation policy; cancellation during APPLY resolves journal before returning.
