# OnePlus Care Pro — v0.4 RC

A technically honest Android maintenance and diagnostics app, tuned for OnePlus / OxygenOS and safe on any
Android 8+ device. Measured facts first, reversible cleaning second, no placebo features.

* **Home** — Healthy / Attention / Critical with the reason, storage/battery/network at a glance, up to three
  explainable recommendations.
* **Smart Scan** — staged, cancellable scan grouped into *Safe to clean · Review recommended · Diagnostic
  findings · No action needed*.
* **Cleaner & Duplicate Cleaner** — only actionable files; SHA-256 + byte verification; one copy is always kept.
* **Safe Trash** — journaled, crash-safe, restorable, never overwrites; optional expiry.
* **App Doctor & Privacy Doctor** — per-app size/cache/usage with "Not available" when unknown; sensitive
  permissions; device security state.
* **Battery & Thermal, Network Doctor, Repair Center** — documented Android APIs and Settings only.
* **Advanced (Shizuku)** — optional, read-only allow-listed diagnostics.

English and Arabic (RTL). No accounts, ads, analytics or uploads.
